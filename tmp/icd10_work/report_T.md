## Decizii manuale

Subzonele lor (C15.3–C15.5, C49.x, C62.x, C71.7 etc.) sunt oricum grupate (D5). `C83.7` „Tumora Burkitt” = `Limfom Burkitt`.
- **Existau sub alt nume:** `Tinea corpului` = `Tinea corporis`, `Thalasemia` = `Anemie talasemica` (plus `Alfa-`/`Beta-talasemie`, `Talasemie minor`/`intermediara`), `Trichinelloza`/`Trichuriaza`/`Trichostrongyliaza` = `Trichineloza`/`Tricocefaloza`/`Tricostrongiloidoza`, `Trypanosomiaza africana` = `Boala somnului`, `Tuberculoza peritoneului` = `Peritonita tuberculoasa`, `Tuberculoza genito-urinara` = `Tuberculoza renala` (are „tuberculoza urogenitala”), `Tremuraturi esentiale` = `Tremor esential`, `Trombangeita obliteranta` = `Boala Buerger`, `Teleangiectazia hemoragica ereditara` = `Boala Osler-Weber-Rendu`, `Tromboza venoasa intracraniana nonpiogenica` = `Tromboza de sinus venos cerebral`, `Tulburari vasculare ale intestinului` = `Ischemie mezenterica`, `Tulburare deliranta indusa` = `Psihoza indusa`, `Tulburare de stres post-traumatic` = `Stres posttraumatic`, `Tulburare de personalitate disociala/instabila/anancastica/evitanta` = `Personalitate antisociala/borderline/obsesiv-compulsiva/evitanta`, `Tulburare de dezvoltare a functiei motorii` = `Dispraxie`, `Tulburari de functionare sociala ... dezinhibitia` = `Tulburare de atasament`, `Tulburare de tic tranzitor` = `Ticuri` (are „ticuri tranzitorii”), `Absenta dorintei sexuale` (F52.0) = `Frigiditate`, `Tulburari hemoragice prin anticoagulante circulante` = `Hemofilie dobandita`, `Tireotoxicoza cu nodul unic` = `Adenom toxic tiroidian`, `Tahicardia ventriculara` = `Aritmie tahicardie ventriculara`, `Tendinita calcificanta` = `Tendinita calcifianta a umarului`, `Tendinita patelei` = `Tendinita rotuliana`, `Traheomalacia congenitala` = `Traheomalacie`, `Tumora lipomatoasa benigna` = `Lipom`, `Torsiunea splinei`/`Torsiunea testiculului` = existente. - **Potriviri automate absurde (corectate):** `F09 Tulburare mentala organica nespecificata = Alcoolism` (reziduală, eliminată), `D56 Thalasemia ~ Acatalazie`, `A75.1 Tifosul recrudescent ~ Artrita idiopatica juvenila`, `F95 Tulburari de ticuri = Sindrom Tourette` (corect ar fi `Ticuri`; oricum există).
