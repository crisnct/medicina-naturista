# Test 5 herbalism

1. Ce face un tonic?
 Tonifica, consolideaza si restabileste functiile anumitor organe.

2. Ce face toata treaba in cazul tonicelor hormonale?
 Substantele asemanatoare hormonilor, pe care le contin.

3. Faceti distinctia intre un adaptogen si un armonizator.
 Adaptogenul este cel care adapteaza organismul la nivelul de stres la care este supus. Armonizatorul este cel care armonizeaza functiile din organism

4. Care este functia generala a ierburilor pe care le numim purificatoare de sange?
 Eliminarea toxinelor din sange.
