| | Noradrenalida (norepinefrina) | Noradrenalina este secretata ca urmare a stresului sau a presiunii sangvine joase. Norepinefrina creste frecventa cardiaca si poate redirectiona fluxul sangvin catre muschi. Aceasta mareste nivelul glucozei din sange pentru a asigura celulelor un aport energetic mai mare. De asemenea, noradrenalina poate cauza contractia muschilor netezi prin activarea α-receptorilor adrenergici. Prin stimularea receptorilor ß1 de la nivelul inimii, noradrenalina poate accelera ritmul batailor si conductibilitatea la nivelul nodului atrio-ventricular, de asemenea marind contractilitatea si excitabilitatea cordului. Norepinefrina este un agent anti-inflamatoriu atunci cand este secretata de locus ceruleus.In calitate de neurotransmitator, este responsabil de dispozitie, regularea presiunii sangvine si excitare. | | |
